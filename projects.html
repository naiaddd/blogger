October 2024 – March 2025

Earlier experiments.

Small scripts, first web pages, and learning by making.

These were early exercises in fetching information, automating routine work, and building simple interfaces. The current projects grew from the same habit of making tools for personal use.

Everyday information

Briefer brought together small tools for news headlines, weather, quotes, and web pages. Related experiments included a Wikipedia fetcher, a command-line EPUB reader, and a random public-dataset link on this website.

Tasks and time

Tasker explored a simple task list with completed-item history. A later planning script calculated available hours across the week, month, quarter, and year.

Automation

Startup scripts opened frequently used tools. An HTML converter prepared text for the web, while a scheduled Git script kept a folder of notes in a repository.
