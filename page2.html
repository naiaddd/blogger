Steps 0: Have notes folder, have github account, have git CLI tools on your system, setup git authentication method of your choice

Step 1: Create an empty git repo https://your-user-name/your-repo
Step 2: Open a terminal and cd to/your/notes/folder
Step 3: Initialise and push git repo with
git init
git remote add origin https://your-user-name/your-repo
git add .
git commit -m "commit the first"
git push -u origin main


Beautiful! Check the repo to see that it uploaded and if it did, now we automate him.

First we create a tiny shell script as follows :

#!/bin/bash

cd /path/to/your/notes || exit

git add .

git commit -m "Automated commit : $(date)"

git push


Save it somewhere convenient, I tucked it inside the notes directory for cleanliness.

Make it executable

chmod +x auto-git.sh

The finishing touch, a cron job :

crontab -e

0 0 * * 1 /path/to/auto-git.sh

Which will set it to run the script every Monday at midnight, adjust for your preference of course.

And that's it! Done!
