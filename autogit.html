Automated Git Pusher

Difficulty : Trivial

Writeup on auto git pusher script

Last updated -

Home Projects

Time : 30 mins (including background research about the meaning of git functions which you don't strictly have to do. I recommend it though)

I was expecting this to be more involved than it turned out to be. In fact, it was extremely easy and appears to work perfectly from the start with no debugging. Which is good, because bash scripts have required significant debugging for me in the past. At time of writing I've only tested a manual execution of the bash script, so we will see when the scheduled automatic push rolls around in... 18 hours, if the cron automation requires any debugging. EDIT: It did not require debugging!

So, I use a note-taking app which saves notes in markdown to a folder on my system. The app has a premium feature for automatic syncing, but as a semi-employed poor in a high cost-of-living region of a high cost-of-living nation doing absolutely everything possible to scrounge my way to financial security, my subscription budget allows for YouTube Premium alone. And even there, I struggle to justify it with Google's declining product quality. But I digress - the automated sync.


Steps 0: Have notes folder, have github account, have git CLI tools on your system, setup git authentication method of your choice

Step 1: Create an empty git repo https://your-user-name/your-repo

Step 2: Open a terminal and cd to/your/notes/folder

Step 3: Initialise and push git repo with

----- git init
----- git remote add origin https://your-user-name/your-repo
----- git add .
----- git commit -m "commit the first"
----- git push -u origin main


Beautiful! Check the repo to see that it uploaded and if it did, now we automate him.

First we create a tiny shell script as follows :

----- #!/bin/bash
----- cd /path/to/your/notes || exit
----- git add .
----- git commit -m "Automated commit : $(date)"
----- git push


Save it somewhere convenient, I tucked it inside the notes directory for cleanliness. Note: You might want to make your notes inside a nested folder for a tidy repo.

Make the script executable with a bash command :

----- chmod +x auto-git.sh

The finishing touch, a cron job :

----- crontab -e
----- 0 0 * * 1 /path/to/auto-git.sh

This command schedules the script to run the script every Monday at midnight, edit as you like.

And that's it! Done!

This is a record of my process on Linux, which fellow Linux noobs can emulate. If you'd like a translation for Windows, let me know, or ask a language model.
